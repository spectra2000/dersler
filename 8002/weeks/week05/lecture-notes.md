# Hafta 05 – CSS Temelleri ve Responsive Tasarım

**Ders:** İnternet Teknolojileri ve Web Programlama  
**Programlama Dili:** CSS  
**Hafta:** 5  

---

## 1. Dersin Amacı

Bu haftanın amacı, web sayfalarının görsel tasarımını
sağlayan CSS dilini öğretmek ve
farklı ekran boyutlarına uyum sağlayan
responsive tasarım kavramını tanıtmaktır.

HTML sayfanın yapısını oluştururken,
CSS sayfanın nasıl görüneceğini belirler.

---

## 2. CSS Nedir?

CSS (Cascading Style Sheets),
HTML elemanlarının görünümünü
kontrol etmek için kullanılan bir stil dilidir.

CSS ile:
- Renkler
- Yazı tipleri
- Boyutlar
- Sayfa düzeni

belirlenir.

CSS, HTML’den bağımsız değildir;
HTML elemanları üzerinde çalışır.

---

## 3. CSS Kullanım Yöntemleri

CSS üç farklı şekilde kullanılabilir.

### Inline CSS

Bir HTML etiketinin içine doğrudan stil yazılır.

Örnek:
p etiketi style özelliği ile renklendirilir.

Inline CSS küçük denemeler için uygundur
ancak büyük projelerde önerilmez.

---

### Internal CSS

CSS kuralları HTML dosyasının
head bölümünde yazılır.

Bu yöntem:
- Küçük sayfalar için uygundur
- Sayfa bazlı stiller sağlar

---

### External CSS

CSS kuralları ayrı bir `.css` dosyasında yazılır
ve HTML dosyasına bağlanır.

Bu yöntem:
- En çok tercih edilen yöntemdir
- Kodun düzenli olmasını sağlar
- Büyük projelerde kullanılır

---

## 4. CSS Seçiciler (Selectors)

CSS seçiciler,
hangi HTML elemanına stil uygulanacağını belirler.

Temel seçici türleri:
- Etiket seçici
- ID seçici
- Class seçici

Seçiciler sayesinde
istenen elemanlar hedeflenir.

---

## 5. Renk ve Yazı Tipi Ayarları

CSS ile metinlerin:
- Rengi
- Yazı tipi
- Yazı boyutu

ayarlanabilir.

Bu ayarlar:
- Okunabilirliği artırır
- Sayfanın görsel kalitesini yükseltir

---

## 6. Kutu Modeli (Box Model)

Her HTML elemanı bir kutu olarak düşünülür.

Kutu modeli şu parçalardan oluşur:
- Content (içerik)
- Padding (iç boşluk)
- Border (kenarlık)
- Margin (dış boşluk)

Kutu modeli,
sayfa düzeninin temelini oluşturur.

---

## 7. Sayfa Düzeni ve Boyutlandırma

CSS ile elemanların:
- Genişliği
- Yüksekliği
- Sayfadaki konumu

kontrol edilebilir.

Bu işlemler,
sayfanın düzenli ve dengeli görünmesini sağlar.

---

## 8. Responsive Tasarım Nedir?

Responsive tasarım,
web sayfasının farklı ekran boyutlarına
uyum sağlamasıdır.

Amaç:
- Telefon
- Tablet
- Bilgisayar

ekranlarında
kullanıcıya iyi bir deneyim sunmaktır.

---

## 9. Media Queries

Responsive tasarımda
media query yapısı kullanılır.

Media query sayesinde:
- Ekran genişliğine göre
- Farklı stiller uygulanabilir

Bu yapı,
mobil uyumlu web sitelerinin temelidir.

---

## 10. CSS’in Web Programlamadaki Rolü

CSS:
- Web sayfalarına görsel kimlik kazandırır
- Kullanıcı deneyimini artırır
- Modern web sitelerinin vazgeçilmezidir

HTML ve CSS birlikte çalışır.

---

- Temel CSS mantığını kavrar
